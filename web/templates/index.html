🔐 API Key 使用说明与风险告知

在启用 AI 辅助判定功能前，请仔细阅读以下条款：

一、功能说明

1. 本功能为平台提供的辅助工具（当前为试用阶段），通过调用您本人提供的 API Key，将购票区间信息发送至您选择的 AI 服务提供商进行二次合规校验及/或联网查询（包括车次、时刻和票价信息）。

二、数据使用承诺

1. 您提供的 API Key 仅在本会话期间使用，用于上述明确告知的目的。API Key 仅保存在当前浏览器标签页的会话存储中（提交判断刷新页面后仍保持连接），关闭标签页或重启浏览器后自动清除，平台不会以任何形式存储或记录您的 API Key。

2. 您的购票区间信息（学校所在地、家庭所在地、出发站、到达站和中转车站）仅用于向 AI 服务提供商发起查询请求，不用于任何其他用途。

三、费用与责任说明

1. 调用您 API Key 所产生的全部费用（如有）由您本人直接向 AI 服务提供商承担，平台不参与费用结算，亦不从中获取任何收益。

2. 您输入的 API Key 为敏感凭证，请确保您处在安全的网络环境（避免公共 WiFi、共享设备等场景），并确认该密钥仅具有您授权范围内的权限。因您自身原因导致 API Key 泄露、被盗用或超授权使用所产生的经济损失，由您自行承担。

四、AI 生成内容免责

1. AI 服务返回的所有结论、建议或信息均为 AI 模型自动生成，仅供参考，不构成购票依据。请您通过 12306 官方渠道最终核实，因依赖 AI 生成内容而造成的任何损失，由您自行承担。

五、撤销与禁用

1. 您可随时关闭浏览器标签页以清除已输入的 API Key；如已在第三方平台授权，请同时前往对应平台撤销令牌。
